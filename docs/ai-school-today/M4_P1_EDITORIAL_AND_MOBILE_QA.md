**สถานะ:** Checklist สำหรับตรวจรับก่อนทำ Preview

## 1. Editorial
- [ ] ทุกหัวข้อใน Content Mapping มีต้นทางที่อ่านได้
- [ ] ไม่ตัดทอนสาระสำคัญเมื่อย่อจาก Markdown
- [ ] ทุกข้อความกล่าวถึง AI อย่างมีข้อจำกัด ไม่สื่อว่า AI ถูกต้องเสมอ
- [ ] เนื้อหาสำหรับเด็กแยกจากคำแนะนำครูและเฉลย
- [ ] ภาษาไทย สะกดคำ และศัพท์ AI สอดคล้องทั้งเล่ม
- [ ] ระบุเวอร์ชัน/วันที่/ผู้ตรวจรับ
- [ ] ไม่มีข้อมูลเด็กจริงหรือข้อมูลที่ควรจำกัดสิทธิ์
- [ ] แหล่งอ้างอิงที่ใช้ยืนยันข้อเท็จจริงตรวจได้จริง

## 2. Mobile/Tablet Preview
- [ ] หน้าแรกและปกแสดงชื่อครบไม่ล้น
- [ ] สารบัญ 13 หัวข้อที่เสนอค้นหาและเลือกได้
- [ ] อ่านบน iPhone แนวตั้งโดยไม่ต้องเลื่อนแนวนอน
- [ ] iPad แนวตั้ง/แนวนอน แสดงหน้าได้ถูกต้อง
- [ ] ปรับอักษร 90–160% และโหมดถนอมสายตาโดยไม่ทับกัน
- [ ] ปุ่มปิด/กลับ/หน้าถัดไป/หน้าก่อน ใช้งานสะดวก
- [ ] อ่านต่อจากหน้าล่าสุดไม่ปะปนหนังสือเล่มอื่น
- [ ] ค้นหาชื่อ/แท็ก/หมวดถูกต้อง
- [ ] ไม่ทำให้ PWA offline/update หรือหนังสือเดิมเสีย
- [ ] Keyboard, focus, reduced motion และ screen reader ผ่านตามเกณฑ์ที่กำหนด
