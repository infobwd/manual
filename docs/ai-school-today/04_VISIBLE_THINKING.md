# บทที่ 4 — จาก “ตรวจคำตอบ” สู่ “ดูวิธีคิด”

สถานะ: M1 Draft สำหรับตรวจรับ | กลุ่มเป้าหมาย: ครูปฐมวัย–ประถมศึกษา

## เป้าหมาย
ครูใช้คำถามและหลักฐานหลายชนิดเพื่อวิเคราะห์กระบวนการคิด ไม่สรุปว่าเด็กเข้าใจเพราะตอบถูกเพียงอย่างเดียว

## กรอบการสังเกต 4 มิติ
1. **เข้าใจโจทย์:** เด็กระบุสิ่งที่โจทย์ถามและข้อมูลที่จำเป็นได้
2. **เลือกวิธี:** เด็กอธิบายเหตุผลที่เลือกวิธีแก้ได้
3. **ตรวจสอบ:** เด็กทบทวนความสมเหตุสมผลและแก้ข้อผิดพลาดได้
4. **ถ่ายโอน:** เด็กใช้ความเข้าใจกับสถานการณ์ใหม่ได้

## คำถามที่ครูใช้ได้ทันที
| ช่วง | คำถาม |
|---|---|
| เริ่มคิด | “โจทย์นี้ต้องการให้เราหาอะไร” |
| เลือกวิธี | “ทำไมจึงเลือกวิธีนี้ มีวิธีอื่นไหม” |
| ระหว่างทำ | “ตอนนี้รู้ได้อย่างไรว่ากำลังทำถูกทาง” |
| พบข้อผิดพลาด | “ตรงไหนที่น่าจะต้องตรวจใหม่” |
| หลังได้คำตอบ | “คำตอบสมเหตุสมผลไหม เพราะอะไร” |
| เปรียบเทียบ AI | “คำตอบตัวอย่างมีขั้นไหนที่เรายังไม่เห็นด้วย” |
| ยืนยัน | “ถ้าเปลี่ยนตัวเลขหรือสถานการณ์ จะทำอย่างไร” |

## ตัวอย่างการวิเคราะห์คำตอบเดียวกัน
โจทย์ 245 + 138 − 96 (คำตอบ 287)
- **เด็ก ก (สมมติ):** ตอบ 287 แต่ไม่สามารถบอกได้ว่า 383 มาจากไหน → ยังต้องตรวจความเข้าใจ
- **เด็ก ข (สมมติ):** ตอบ 297 แต่แสดงขั้นตอนชัด พบว่าลบผิดหลักสิบ → มีวิธีคิดบางส่วนถูก ต้องช่วยแก้ข้อผิดพลาดเฉพาะจุด
- **เด็ก ค (สมมติ):** ตอบ 287 อธิบายลำดับและตรวจด้วยการบวกย้อนกลับ → มีหลักฐานความเข้าใจมากกว่าแค่ตอบถูก

ห้ามใช้กรณีสมมติเหล่านี้แทนผลเด็กจริง

## แบบบันทึกหลักฐานย่อ
| มิติ | หลักฐานที่สังเกต | ขั้นต่อไป |
|---|---|---|
| เข้าใจโจทย์ | เด็กพูด/เขียนสิ่งที่โจทย์ถาม | ให้ชี้ข้อมูลสำคัญ |
| เลือกวิธี | อธิบายว่าทำไมบวกก่อนลบ | เปรียบเทียบวิธีอื่น |
| ตรวจสอบ | ลองแทนค่าหรือคำนวณย้อน | ฝึกตรวจคำตอบ |
| ถ่ายโอน | ทำโจทย์ใหม่ด้วยตนเอง | เพิ่มระดับความยากอย่างเหมาะสม |

## วิธีให้ Feedback ที่ส่งเสริมการคิด
แทน “ผิด ทำใหม่” → “ขั้นตอนแรกถูกแล้ว ลองตรวจการลบหลักสิบอีกครั้ง”
แทน “เก่งมาก ถูกทุกข้อ” → “อธิบายได้ชัดว่าทำไมต้องบวกก่อน แล้วตรวจคำตอบด้วยวิธีอื่นได้ไหม”

## ตัวอย่างปฐมวัย
เด็กจัดกลุ่มรูปทรง ครูถาม “ทำไมวางชิ้นนี้ไว้กลุ่มนี้” ให้เด็กชี้ พูดหรือทดลองย้ายชิ้นจริง; ไม่จำเป็นต้องใช้ AI กับเด็กโดยตรง
