# AI & School Today — คู่มือครูสำหรับการเรียนรู้ในยุค AI

สถานะ: **แผนร่าง M0 — ยังไม่ใช่คู่มือเผยแพร่หรือข้อกำหนดทางการ**

หัวข้อหลัก: AI in Learning — เมื่อเด็กใช้ AI แล้ว ห้องเรียนจะเปลี่ยนอย่างไร (27 ตุลาคม 2569)

หลักคิด: **AI ช่วยการเรียนรู้ แต่ไม่แทนกระบวนการคิดของเด็ก**

## ห้าคำถามตั้งต้น
1. เมื่อเด็กใช้ AI ทำการบ้านหรือหาคำตอบ ครูควรมองอย่างไร
2. ออกแบบงานอย่างไรให้ AI ช่วยเด็กได้ แต่ยังเห็นว่าเด็กคิดอะไรด้วยตัวเอง
3. จากตรวจคำตอบเปลี่ยนเป็นดูวิธีคิดได้อย่างไร
4. สอนเด็กให้รู้จักใช้ข้อมูลและตั้งคำถามกับ AI ได้อย่างไร
5. การประเมินแบบไหนยังวัดการเรียนรู้จริงในวันที่ AI สร้างคำตอบได้
