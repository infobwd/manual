# บทที่ 8 — ใช้ AI พัฒนาการสอนผ่าน PLC อย่างต่อเนื่อง

สถานะ: M1 Draft สำหรับตรวจรับ | ไม่ใช่คำสั่งให้แก้ระบบ PLC หรือ WD Growth

## เป้าหมาย
ครูร่วมกันวางแผน ทดลอง เก็บหลักฐานไม่ระบุตัวตน สะท้อนผล และปรับกิจกรรม AI-assisted อย่างต่อเนื่อง โดยคงบทบาทครูเป็นผู้ตัดสินใจ

## วงจร PLC 6 ขั้น
1. **ระบุปัญหา:** เช่น เด็กตอบถูกแต่ไม่สามารถอธิบายวิธีคิด
2. **ตั้งเป้าหมาย:** กำหนดทักษะที่สังเกตได้และเกณฑ์ก่อนสอน
3. **ร่วมออกแบบ:** ปรับใบงาน กำหนดขอบเขต AI และเครื่องมือประเมิน
4. **ทดลองสอน:** ครูใช้กิจกรรมกับชั้นเรียนตามบริบทจริง
5. **เก็บหลักฐานและสะท้อน:** บันทึกเฉพาะข้อมูลที่จำเป็นในระบบภายใน; ใช้ข้อมูลสรุปไม่ระบุตัวตนเมื่อเผยแพร่
6. **ปรับและติดตาม:** แก้กิจกรรม ทดลองใหม่ และเทียบความก้าวหน้าตามหลักฐาน

## แผนทดลอง 4 สัปดาห์ (ตัวอย่าง)
| สัปดาห์ | กิจกรรม | ชิ้นงาน |
|---|---|---|
| 1 | เลือกทักษะ เก็บ baseline และร่วมออกแบบ | แผน/เกณฑ์ |
| 2 | ทดลองกิจกรรมครั้งที่ 1 | บันทึกสังเกต |
| 3 | วิเคราะห์จุดติดขัดและปรับกิจกรรม | ใบงานฉบับปรับ |
| 4 | ทดลองซ้ำและสรุปผล | Reflection/แผนต่อ |

แผน 4 สัปดาห์นี้เป็น **ตัวอย่างเฉพาะการอบรม AI** ไม่ใช่การเปลี่ยนวงจร PLC 7 สัปดาห์ของโรงเรียน หากนำไปใช้จริงให้แมปกิจกรรมเข้ากับปฏิทิน PLC ที่ได้รับอนุมัติแล้ว

## คำถามในการประชุม PLC
- เด็กแสดงความเข้าใจด้วยตนเองในขั้นไหน?
- AI ช่วยการสอนส่วนใด และส่วนใดทำให้หลักฐานความคิดไม่ชัด?
- นักเรียนที่ต้องการความช่วยเหลือเพิ่มเติมมีรูปแบบข้อผิดพลาดอะไร?
- กิจกรรมใหม่ดีกว่าเดิมจากหลักฐานอะไร และมีข้อจำกัดใด?
- รอบต่อไปครูจะปรับคำถาม ใบงาน หรือวิธีประเมินอะไร?

## เชื่อมโยง WD Growth อย่างระมัดระวัง
- ใช้ผลการประเมินทักษะรายบุคคลจากระบบต้นทางภายใต้สิทธิ์ที่กำหนด เพื่อช่วยเลือกจุดพัฒนา
- ไม่เปลี่ยน schema คะแนน รูบริก การอนุญาตเข้าถึง หรือ workflow ยืนยันคะแนนโดยอัตโนมัติ
- ไม่คัดลอกชื่อ เลขที่ คะแนนรายคน ภาพเด็ก หรือข้อมูลระบุตัวบุคคลมาเก็บใน repository manual ซึ่งเป็นสาธารณะ
- การบันทึกผลจริงให้ทำในระบบภายในที่โรงเรียนอนุมัติ ไม่ใช้ Markdown สาธารณะเป็นฐานข้อมูลนักเรียน

## การตรวจรับรอบทดลอง
- มีเป้าหมายและหลักฐานตั้งต้น
- ครูได้ทดลองสอนและสะท้อนผลร่วมกัน
- มีหลักฐานก่อน–หลังที่เทียบได้ โดยไม่อ้างผลเกินข้อมูล
- มีการปรับกิจกรรมจากสิ่งที่พบจริง
- ปฏิบัติตามการคุ้มครองข้อมูลและสิทธิ์เข้าถึง

## ขอบเขต M1
เอกสารนี้เป็นคู่มือวิธีดำเนินงาน ไม่ได้เชื่อมต่อ API กับ plc.esdc.app หรือ wd.esdc.app ไม่สร้างงานอัตโนมัติ และไม่เผยแพร่ข้อมูลผลนักเรียน
