# M3 — Checklist วิทยากรก่อน ระหว่าง และหลังซ้อมอบรม

สถานะ: Template สำหรับกรอกผลซ้อมจริงในพื้นที่ภายในที่ได้รับอนุญาต

## A. ก่อนซ้อม (T−7 ถึง T−1 วัน)
- [ ] ยืนยันผู้เข้าร่วม จำนวนกลุ่ม สถานที่ และอุปกรณ์
- [ ] ตรวจสไลด์/คู่มือ/ใบงานตรง revision ล่าสุดใน main
- [ ] เตรียมชุดเอกสารผู้เข้าอบรม **ไม่มีเฉลย** และชุดวิทยากร **มีเฉลย**
- [ ] ตรวจเฉลยคณิต 245+138−96 = 287 และโจทย์เปลี่ยนเป็น 277
- [ ] เตรียมแหล่งข้อมูลต้นฉบับสำหรับกิจกรรมผีเสื้อ และทดสอบเปิดได้
- [ ] ตรวจอายุ/เงื่อนไขเครื่องมือ AI และนโยบายข้อมูลของโรงเรียน
- [ ] ใช้ตัวอย่างสมมติ ไม่ใช้ภาพ ชื่อ หรือคะแนนนักเรียนจริง
- [ ] เตรียมวิธีดำเนินกิจกรรมโดยไม่ใช้อินเทอร์เน็ต
- [ ] แต่งตั้งผู้จับเวลาและผู้บันทึก feedback

## B. ระหว่างซ้อม (180 นาที)
- [ ] 00:20 จบเปิดประเด็นและ pre-test
- [ ] 00:50 จบจริยธรรม/กติกา
- [ ] 01:30 จบออกแบบใบงาน
- [ ] 02:00 จบตรวจข้ออ้างและแหล่งข้อมูล
- [ ] 02:40 จบรูบริกและโจทย์ยืนยัน
- [ ] 03:00 จบ action plan, post-test และ exit ticket
- [ ] ครูผู้ทดลองเข้าใจคำสั่งกิจกรรมโดยไม่ต้องอธิบายเพิ่มมาก
- [ ] ใบงานและรูบริกใช้ได้จริงตามช่วงวัย
- [ ] ไม่มีข้อมูลส่วนบุคคลปรากฏในสื่อหรือ prompt
- [ ] บันทึกปัญหาเรื่องเวลา ความชัดเจน และการเข้าถึง

## C. หลังซ้อม
- [ ] สรุปเวลาจริงแต่ละช่วงและส่วนที่เกิน/ขาด
- [ ] สรุปข้อที่ pre/post-test ทำให้สับสน
- [ ] ทบทวนความสอดคล้องคะแนนรูบริกระหว่างผู้ประเมิน
- [ ] แก้คำสั่ง/สื่อและบันทึก revision
- [ ] ให้ผู้รับผิดชอบตรวจรับเนื้อหาและความปลอดภัย
