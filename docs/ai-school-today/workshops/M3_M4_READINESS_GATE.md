- [ ] ผู้รับผิดชอบอนุมัติการเผยแพร่และการเปิดสิทธิ์เข้าถึง

## เกณฑ์ Go/No-Go
- **Go:** รายการสำคัญข้างต้นผ่านครบและมีผู้อนุมัติ
- **Revise:** มีข้อผิดพลาดที่แก้ได้และต้องตรวจซ้ำ
- **No-Go:** ข้อมูลส่วนบุคคลรั่วไหล เนื้อหาผิดสาระสำคัญ หรือระบบเผยแพร่เสี่ยงกระทบหนังสือเดิม

## แนวทางเทคนิค M4 (แผนเท่านั้น)
1. สำรวจโครงสร้าง e-book/PWA และระบบ catalog ปัจจุบันแบบ read-only
2. กำหนด metadata: ชื่อชุด ผู้เขียน/ผู้รับผิดชอบ เวอร์ชัน หมวดหมู่ วันที่ตรวจรับ
3. เตรียมหน้าปก/สารบัญ/ลิงก์บท/ไฟล์ดาวน์โหลดตามระบบที่มีอยู่
4. ทดลองบน preview หรือ staging ก่อน
5. ตรวจบนมือถือและแท็บเล็ต รวมถึงการเข้าถึงด้วยแป้นพิมพ์และการอ่านภาษาไทย
6. เผยแพร่หลังได้รับอนุมัติแยกต่างหาก พร้อม rollback plan
