# WD Books FLIP-08A — ปุ่มกลับนิ้วโป้งขวา + โหมดมืดพลิกกระดาษ (28 ต.ค. 2569)

**Scope:** ปรับเล็กเฉพาะโหมดพลิกกระดาษของหนังสือทดลองหนึ่งเล่ม โดยรักษาระบบเปิดอ่านเดิม การแบ่งหน้า และเสียงอ่านตามเดิม

## ข้อค้นพบจากภาพ iPhone PWA

1. ปุ่ม “กลับไปอ่าน” อยู่สูงเกินกดด้วยนิ้วโป้งขวาในมือเดียว
2. ปุ่มวงกลมครึ่งสีเดิมคือ **ลดการเคลื่อนไหว**, ไม่ใช่โหมดมืด; ใช้รูปทรงเดียวกันจึงทำให้เข้าใจผิด
3. โหมดพลิกกระดาษอยู่ใน iframe ซึ่งไม่รับธีมของ Reader แม่โดยอัตโนมัติ แม้ Reader เดิมมี light/sepia/night

## งานที่ทำ (Option A)

- บนจอมือถือแนวตั้ง (<=690px, สูง >=501px) ย้ายปุ่ม **กลับไปอ่าน** ลงมุมขวาล่างของ modal แม่โดยใช้พื้นที่ footer สำรอง **62px + safe-area** ไม่ทับกระดาษหรือแถบนำทางก่อนหน้า/ถัดไป; จอแนวนอนที่เตี้ยใช้ตำแหน่งบนเดิมเพื่อไม่แย่งเนื้อหา
- เพิ่มปุ่ม **☾ เปิดโหมดมืด / ☀ เปลี่ยนเป็นโหมดสว่าง** ที่ toolbar ของ flipbook มี `aria-label`, `aria-pressed` และสีที่ตัดกันชัดเจน
- ปุ่มโมชั่นเปลี่ยนจากวงกลมครึ่งสีเป็น **↔ โมชั่น** (คำว่าโมชั่นมองเห็นได้), ยังควบคุม reduced motion เหมือนเดิม
- เปลี่ยนสีพื้นกระดาษ หัวข้อ เนื้อหา อ้างอิง กรอบคำแนะนำ ปุ่มนำทาง และพื้นที่รอบหนังสือในโหมดมืด โดยไม่ปรับฟอนต์/ขนาดหน้า/เนื้อหาหรือกระทบ engine
- ส่งค่า `theme` จาก Reader ไปยัง iframe ใน URL; เมื่อผู้ใช้กดสลับสี iframe ส่ง postMessage ไปหา parent ตาม `origin` และ `bookId` ที่ตรวจแล้ว, parent เรียก `WD_EXPERIENCE.setTheme()` เพื่อบันทึก **storage เดิม**; iframe ไม่มี storage ใหม่
- PWA version **1.3.61**, เปลี่ยน JS/CSS query version ใน iframe เพื่อไม่ค้างไฟล์เก่า; Service Worker และ splash ใช้เวอร์ชันเดียวกัน
