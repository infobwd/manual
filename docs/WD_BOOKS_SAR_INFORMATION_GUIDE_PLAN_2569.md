# คู่มือ SAR และสารสนเทศสถานศึกษา — แผนจัดทำและตรวจสิทธิ์เผยแพร่

**สถานะ:** ร่างแผน / ยังไม่เผยแพร่เนื้อหา SAR จริง
**ปลายทาง:** WD Books หมวดเสนอใหม่ "สารสนเทศสถานศึกษา" (ยังไม่เพิ่มหมวดใน Production)
**ต้นทางที่ตรวจแล้ว:** Private `infobwd/nopparut-pa` (`README.md`, `years/2569/README.md`, `years/2570/PA_2570_MASTER_PLAN.md`, `shared/DATA_GOVERNANCE.md`).

## สิ่งที่ตรวจพบ
- Repo PA กลางเป็นพื้นที่วางแผนต่อเนื่องหลายปี; ปี 2569 เป็นเพียงการอ้างอิงกลับไปยัง Repo ผลนำเสนอเดิม และยังไม่ได้คัดลอก/รับรองหลักฐานครบถ้วน
- แผน PA 2570 ระบุให้ทบทวน SAR และหลักฐานก่อนกำหนดตัวชี้วัด; ตัวเลข/เป้าหมายเดิมไม่ควรถูกใช้เป็นผลยืนยันใหม่
- นโยบายข้อมูล Repo PA เน้นผลรวม ไม่ระบุตัวนักเรียนและตรวจสอบที่มา

## โครงหนังสือที่เสนอ
1. SAR คืออะไรและใช้ประโยชน์อย่างไร (คำอธิบายทั่วไป)
2. โครงสร้างรายงาน SAR ของสถานศึกษา (หัวข้อและนิยาม)
3. อ่านตัวชี้วัดและผลประเมินอย่างไร (ไม่ตีความเกินหลักฐาน)
4. เชื่อม SAR กับแผนพัฒนาคุณภาพ / PA / WD Growth อย่างระมัดระวัง
5. ตัวอย่างการอ่านตารางและกราฟด้วย **ข้อมูลสมมติที่ระบุชัด**
6. รายการตรวจสอบก่อนเผยแพร่ผล SAR จริง: ปีการศึกษา, ฉบับอนุมัติ, แหล่งอ้างอิง, ขอบเขตข้อมูล, การปกปิดข้อมูลรายบุคคล

## เงื่อนไขก่อนสร้างหนังสือจริง
- ระบุ SAR ฉบับต้นทางและปีการศึกษา (เช่น SAR 2568) พร้อมตรวจฉบับเต็ม
- แยกผลจริงที่อนุมัติให้เผยแพร่จากข้อมูลส่วนบุคคล/ผลร่าง
- ขอความเห็นชอบต่อชุดตัวเลขและตารางที่จะเปิดสาธารณะก่อนนำเข้าหนังสือ
- สร้างหนังสือผ่าน content PR แยกจาก CAT-01B; กำหนด book ID ถาวร, หมวดใหม่, สถานะ และทดสอบ CAT-01A
- ไม่ฝังลิงก์ที่เข้าถึงได้เฉพาะ Private Repo เป็นแหล่งให้ผู้อ่านทั่วไปเปิดอ่าน
- ห้ามคัดลอกเอกสาร SAR เต็มฉบับโดยไม่ตรวจความเหมาะสมและสิทธิ์เผยแพร่

## สิ่งที่ทำได้ก่อนมีคอม
เตรียมโครงเรื่อง, metadata และแผนตรวจหลักฐานผ่าน GitHub; รอเอกสาร SAR ที่ตรวจสอบได้ก่อนสร้างบทผลจริง. ไม่แก้ Production, ไม่แตะข้อมูลผู้ใช้, ไม่ Merge อัตโนมัติ.
