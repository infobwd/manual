# WD Books — โหมดผู้ประกาศข่าว (Teleprompter) สำหรับบทพูด 7 ข้อ

ปรับปรุง: 27 ตุลาคม 2569  
สถานะ: เพิ่มบทพูดข้อ 6–7 ในเล่มเดิม และเตรียมอัปเดต PWA; ต้องทดสอบบนเครื่องจริงหลัง Merge  
เวอร์ชันเป้าหมาย: **1.3.50**

## ขอบเขต

เพิ่มปุ่ม **🎙 บทพูด** เฉพาะหนังสือ “คู่มือฝึกพูด 7 คำถามการศึกษาในยุค AI” เมื่อเปิดอ่านใน Reader ปุ่มจะเปิดหน้าจอข้อความเต็มจอแบบผู้ประกาศข่าว โดยยังเก็บหน้าหนังสือเดิมอยู่ด้านหลัง

- เลือกบทพูด 1–7 ได้ โดยอ่านจากบทพูดต้นฉบับในทะเบียนหนังสือ ไม่คัดลอกหรือเขียนบทใหม่
- ข้อความที่แสดงเริ่มตั้งแต่ “สวัสดีครับ” ถึง “ขอบคุณครับ” ไม่รวมส่วนวิเคราะห์/คำแนะนำหลังบทพูด
- เปิดแล้วไม่เลื่อนเองจนกด **▶ เริ่มเลื่อน**; กด **⏸ หยุดเลื่อน** และ **▶ เลื่อนต่อ** ได้
- ตั้งความเร็ว 8–80 พิกเซลต่อวินาที, ขนาดตัวอักษร 24–64 พิกเซล, เริ่มบทเดิมใหม่, บทก่อน/ถัดไป
- เลื่อนขึ้นด้วยนิ้วได้แม้ไม่ได้เปิดการเล่น และปิดกลับหนังสือเดิมได้
- ปิดหน้าต่างหรือเปลี่ยนแอปแล้วหยุดเลื่อน ป้องกันข้ามประโยคแบบไม่ตั้งใจ
- ปิดโหมดแล้วไม่กระทบประวัติหน้าอ่าน บุ๊กมาร์ก หนังสือของฉัน เสียง หรือข้อมูล localStorage

## วิธีใช้

1. เปิด WD Books → หมวด **งานวิชาการ** → “คู่มือฝึกพูด 7 คำถามการศึกษาในยุค AI”
2. แตะ **🎙 บทพูด** ที่แถบเครื่องมือด้านบนของหน้าอ่าน
3. เลือกข้อ 1–7, ปรับตัวอักษรและความเร็ว
4. กด **▶ เริ่มเลื่อน** เพื่อให้บทพูดค่อย ๆ เลื่อนขึ้น หรือ **⏸ หยุดเลื่อน** เพื่อพัก
5. กด **↺ เริ่มใหม่** หรือ **ถัดไป** เพื่อเปลี่ยนบท; กด **✕ ปิด** กลับไปอ่านตามเดิม

**เคล็ดลับฝึกพูด:** เริ่มความเร็ว 30 px/วินาที แล้วปรับตามจังหวะจริง; ขณะฝึกให้มองใกล้เลนส์และอ่านแบบเล่าเรื่อง ไม่ท่องตามข้อความทุกคำ

## สิ่งที่ไม่รวมในรอบนี้

ไม่ใช้กล้อง ไมโครโฟน ตรวจจับความเร็วเสียง หรือเชื่อม AI ภายนอก ไม่ให้แอปเลื่อนต่อเมื่อจอล็อกหรือออกจากแอป ไม่แก้ไขความเร็วเครื่องฟังหนังสือ และไม่เปลี่ยน Reader หลักทุกเล่มเป็น teleprompter

## ตรวจรับ Local-First

รันบน Windows / VS Code:

```powershell
node tests/teleprompter.smoke.cjs
node tests/library.smoke.cjs
node tests/pwa-reader.smoke.cjs
py -m http.server 4173 --bind 127.0.0.1
```

เปิด http://127.0.0.1:4173/ และทดสอบ:

- [ ] หนังสือเป้าหมายมีปุ่ม 🎙 บทพูด; หนังสืออื่นไม่แสดงปุ่ม
- [ ] เปิด/ปิดได้โดยไม่เปลี่ยนหน้าหนังสือหรือหนังสือที่เลือก
- [ ] ครบ 7 บทและไม่มีคำแนะนำแทรกในบทอ่าน
- [ ] เล่น → หยุด → เล่นต่อ โดยไม่กระโดดกลับต้นเอง
- [ ] เลื่อนด้วยนิ้ว ปรับความเร็วและขนาดตัวอักษรได้
- [ ] จบบทแล้วหยุด ไม่ข้ามบทโดยไม่กด
- [ ] เมื่อออกจากแอป/สลับแท็บ การเลื่อนหยุด
- [ ] ปุ่มบทก่อน/บทถัดไป/เริ่มใหม่/ปิด และ Esc ใช้ได้
- [ ] Mobile: ปุ่มควบคุมไม่ทับข้อความ กดง่าย จอแนวตั้งและแนวนอน
- [ ] PWA แสดงเวอร์ชัน 1.3.50 และพบอัปเดตโดยไม่ล้างข้อมูลในเครื่อง
- [ ] ทดสอบบน iPhone/iPad จริงและเดสก์ท็อปก่อนยืนยันว่าผ่านทั้งหมด

## ข้อควรระวัง

หน้าจอ Teleprompter เป็นโหมดเลื่อน **ข้อความที่มีอยู่แล้ว** ไม่ใช่การสร้างบทพูดใหม่ และไม่รองรับการเลื่อนขณะล็อกหน้าจอ ระบบจะหยุดเมื่อย้ายไปแอปอื่น เหมาะกับการวางเครื่องไว้ใกล้เลนส์เพื่ออัดคลิป โดยไม่จำเป็นต้องเปิด AI หรือส่งข้อมูลออกนอกเครื่อง
