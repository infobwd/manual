# WD Growth Teacher Development — แนวทางพัฒนาการจัดการเรียนรู้ของครู

> คู่มือพัฒนาครูแยกจากชุดสารสนเทศ WD Growth Insights ป.1–ป.5 สำหรับ WD Books | ปีการศึกษา 2569 | โรงเรียนบ้านวังด้ง
> สถานะ: CONTENT DRAFT / ยังไม่เผยแพร่เป็นหนังสือใน PWA / ไม่ใช่ผลรับรอง

## 1. เหตุใดจึงประเมิน
Baseline A1.0 เป็นจุดเริ่มต้นเพื่อค้นหาว่าผู้เรียนทำอะไรได้แล้ว และต้องการการสนับสนุนตรงไหน ไม่ใช่เครื่องมือจัดอันดับเด็กหรือประเมินคุณค่าครู

## 2. อ่านข้อมูลอย่างระมัดระวัง
แหล่งอ้างอิงภายใน: infobwd/wd-standard, docs/WD_GROWTH_P5_BASELINE_A1_RECONCILIATION_ROUND2_2569.md (29 ต.ค. 2569). คะแนนที่ถอดจากภาพยังเป็น DRAFT ต้องให้ครูตรวจรับรายข้อก่อนใช้สรุปเชิงสถิติหรือกำหนดผลรายคน; มีใบที่คะแนนยังว่างและการประเมินบางทักษะยังไม่ครบ. ห้ามตีความช่องว่างเป็นศูนย์ และไม่เผยแพร่เลขที่พร้อมคะแนนรายคนบนเว็บสาธารณะ

## 3. ประเด็นสำหรับครู
- ภาษาไทย: แยกการอ่านเข้าใจ การอ่านวิเคราะห์ และการเขียนสื่อความ ไม่สรุปจากคะแนนรวมอย่างเดียว
- คณิตศาสตร์: วิเคราะห์ความคลาดเคลื่อนรายข้อว่ามาจากการอ่านโจทย์ ความเข้าใจแนวคิด หรือวิธีคำนวณ
- ภาษาอังกฤษ: แยกฟัง พูด อ่าน เขียน; เมื่อข้อมูลไม่ครบให้ติดตามการประเมินก่อนตีความ
- เลือกเป้าหมายพัฒนาไม่เกิน 1–2 ทักษะต่อคนตามข้อมูลที่ครูตรวจรับแล้ว

## 4. วงจรพัฒนาการสอนระยะสั้น
1. **ตรวจรับ** ครูเทียบกระดาษจริงกับคะแนนรายข้อและสถานะขาดข้อมูล
2. **วิเคราะห์ร่วม** ทีมครูเลือกทักษะที่เป็นอุปสรรคต่อการเรียนรู้ พร้อมตรวจตัวอย่างคำตอบจริง
3. **ออกแบบกิจกรรม** ฝึกสั้น 10 นาที สัปดาห์ละ 3 ครั้ง โดยมีโจทย์หลายระดับและวิธีช่วยเหลือที่เหมาะสม
4. **ทดลองและสังเกต** ใช้ PLC แบบไม่ให้คะแนนหรือจัดอันดับครู สังเกตว่าผู้เรียนคิดและทำอะไรได้ด้วยตนเอง
5. **ติดตามหลักฐาน** เก็บงานสั้นหรือการตอบรายทักษะทุก 2 สัปดาห์ โดยใช้เกณฑ์เดียวกันและไม่เผยแพร่ข้อมูลส่วนบุคคล
6. **ปรับการสอน** ถ้ายังไม่ก้าวหน้าให้เปลี่ยนวิธีช่วยเหลือ ไม่ใช่เพียงเพิ่มแบบฝึก

## 5. ตัวอย่างกิจกรรม
**ภาษาไทย — อ่านแล้วอธิบายเหตุผล:** อ่านข้อความสั้น ถามว่าเกิดอะไรขึ้น และใช้ข้อความใดเป็นหลักฐาน ตอบด้วยคำพูดก่อนเขียน 1–2 ประโยค

**คณิตศาสตร์ — อธิบายวิธีคิด:** ให้แก้โจทย์สั้นหนึ่งข้อ แล้วอธิบายว่าเลือกวิธีใด ทำไม และตรวจคำตอบอย่างไร

**ภาษาอังกฤษ — ฟัง พูด อ่าน เขียนแบบเชื่อมโยง:** ฟังคำหรือประโยคสั้น จับคู่ภาพ พูดตามบริบท อ่านคำ และเขียนตอบอย่างเหมาะกับจุดเริ่มต้นของผู้เรียน

## 6. ผู้บริหารควรสนับสนุนอย่างไร
จัดเวลาให้ครูตรวจข้อมูลและประชุมสั้นเป็นทีม จัดสื่อที่ใช้ได้จริง ติดตามการปรับกิจกรรมจากหลักฐาน ไม่ใช้คะแนนดิบเพื่อเปรียบเทียบครูหรือห้องเรียน และให้ PLC เป็นพื้นที่ช่วยกันคิด

## 7. เกณฑ์ก่อนเผยแพร่เป็นหนังสือใน WD Books
- ยืนยันข้อความที่เป็นข้อเท็จจริงกับต้นฉบับ และแยกข้อเสนอจากผลจริง
- ห้ามเผยแพร่ชื่อ ภาพต้นฉบับ เลขที่ผูกกับคะแนน หรือข้อมูลที่ระบุตัวเด็กได้
- ทบทวนความเสี่ยงจากกลุ่มตัวอย่างขนาดเล็ก; หากข้อมูลรวมทำให้ระบุตัวได้ ให้งดเผยแพร่ตัวเลข
- นำเข้าทะเบียนหนังสือด้วย PR แยกหลังตรวจรูปแบบ schema และ PR UI ที่ยังเปิดอยู่
- ทดสอบ Reader, Flipbook, เสียงอ่าน, Mobile/Tablet, PWA และ offline cache ก่อน Merge

## 8. คำถามชวนคุยใน PLC
1. ข้อใดแสดงความเข้าใจที่แท้จริงของเด็ก และเรารู้ได้อย่างไร?
2. ความผิดพลาดใดเกิดซ้ำ และกิจกรรมใดจะช่วยให้เด็กอธิบายความคิดได้?
3. ในสองสัปดาห์ข้างหน้า เราจะเก็บหลักฐานเล็ก ๆ อะไรเพื่อรู้ว่าแนวทางได้ผล?
