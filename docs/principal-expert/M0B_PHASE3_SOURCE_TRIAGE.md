# M0-B ระยะ 3 — คัดกรองแหล่งฉบับเต็มและแยกหลักฐาน

ตรวจ 24 ตุลาคม 2569

## ผลค้นครั้งนี้
ยัง **ไม่พบรายงานวิจัยฉบับเต็มที่พิสูจน์ได้ว่าเป็นผลงานชิ้นเดียวกับที่ผ่านการอนุมัติ** ของรายชื่อ 15 รายในฐาน M0-B; จึงยังไม่มีการสกัดระเบียบวิธีจากผลงานผู้ผ่านโดยตรง

### แหล่งค้นที่ตรวจสอบ
1. [ระบบคลังวิจัยและนวัตกรรม สพฐ.](https://ordc.obec.go.th/) — คลังสืบค้นงานวิจัยมากกว่า 3,000 เรื่อง; ยังไม่ยืนยันไฟล์ตรงกับรายชื่อผู้ผ่าน
2. [สำนักงาน ก.ค.ศ. ภารกิจระบบตำแหน่งและวิทยฐานะที่ 1](https://otepc.go.th/th/otepc03.html) — แหล่งประกาศการอนุมัติ; **ไม่ใช่คลังรายงานฉบับเต็มโดยอัตโนมัติ**
3. [บทความวิจัย แนวทางพัฒนาสถานศึกษาแห่งนวัตกรรมฯ (2569)](https://so04.tci-thaijo.org/index.php/JAPDEAT/article/view/286656) — พบหน้าเผยแพร่บทความวิจัยที่มีรายละเอียดวิธีวิจัยและผล; **ยังไม่มีหลักฐานว่าเป็นผลงานที่ผ่านการอนุมัติวิทยฐานะ**
4. [บทความวิชาการ การพัฒนานวัตกรรมการบริหารงานวิชาการฯ (2569)](https://so05.tci-thaijo.org/index.php/Kanchana-editor/article/view/287548) — พบลิงก์ PDF และบทคัดย่อ; เป็น **บทความวิชาการ ไม่ใช่หลักฐานการผ่านประเมิน**

## กฎคัดกรองก่อนเปลี่ยนสถานะ
- ต้องจับคู่ **ชื่อบุคคล + ชื่อผลงานตรง + หน่วยงาน/ช่วงเวลา + หลักฐานประกาศอนุมัติ** จึงจะเชื่อมไฟล์กับผู้ผ่าน
- ต้องเปิด PDF และตรวจเนื้อหา/หน้า/ผู้เขียนก่อนตั้งสถานะ A
- ผลงานตีพิมพ์ในวารสาร ≠ ผลงานที่ได้รับอนุมัติเลื่อนวิทยฐานะโดยอัตโนมัติ
- ห้ามสร้างผลการวิเคราะห์เชิงลึกจากเพียงบทคัดย่อหรือชื่อเรื่อง

## คิวค้นลึกต่อ
- นายนิพัทธ์ อาจมิตร — โรงเรียนอัจฉริยะและดิจิทัล
- นางสาวสิมาพร ลิ้มไพบูลย์ — PLC และโรงเรียนคุณภาพ
- นางอ่อนจันทร์ นุชบูรณ์ — การบริหารแบบมีส่วนร่วม
- นายสุรพล พรชัย — เทคโนโลยีดิจิทัลกับคุณภาพผู้เรียน
- นายโกสินทร์ สวัสดิ์ชัย — การมีส่วนร่วมของครอบครัวและเครือข่าย

## ข้อเสนอเชิงปฏิบัติ WD Growth Together
ใช้บทความวิจัย/วิชาการทั่วไปเป็นฐานแนวคิดและตรวจเอกสารอ้างอิงได้ **แต่ต้องแยกจากตัวอย่างผู้ผ่าน** และยังไม่ควรเขียนว่ามีตัวอย่างผลงานผ่านที่อ่านฉบับเต็มแล้ว
