## 1. ขอบเขตและหลักตรวจสอบ
ตรวจความครอบคลุมจากเอกสารที่บันทึกไว้ในชุด 1–7; ตารางนี้เป็น **ทะเบียนสถานะตามเอกสาร** ไม่ใช่การยืนยันว่าได้เปิดอ่าน PDF ทุกรายการใหม่ในรอบที่ 8. ใช้ระดับ `candidate`, `publisher_verified`, `abstract_reviewed`, `full_text_checked`, `page_verified` อย่างระมัดระวัง. กรณีตรวจเพียงบางหน้าระบุ `partial_page_verified` ไม่เหมารวมทั้งงาน

## 4. Acceptance criteria สำหรับ Gate 14.2
- [ ] ทุกธีมมีแหล่งที่เหมาะสมและตรวจต้นฉบับในระดับเพียงพอต่อข้ออ้างที่จะนำไปใช้
- [ ] ทุกข้ออ้างสำคัญมีแหล่งและเลขหน้า **เมื่ออ้างจาก PDF**; ถ้าไม่มีเลขหน้าต้องระบุว่ายังไม่ตรวจ
- [ ] มีหลักฐานไทยที่สัมพันธ์กับบริบทประถมศึกษาและข้อจำกัดด้านการถ่ายโอนผล
- [ ] มีตารางสกัดหลักฐาน: ผู้วิจัย/ปี, กลุ่มตัวอย่าง, แบบวิจัย, ผล, ข้อจำกัด, ประเด็นเชื่อม WD
- [ ] มี search log ที่ตรวจซ้ำได้; ห้ามสร้างจำนวนผลค้นหรือ PRISMA flow ที่ไม่ได้บันทึกจริง
- [ ] แยก **ทฤษฎี/ข้อเสนอออกแบบ**, **ผลวิจัยภายนอก**, และ **ผลจริง WD Growth** อย่างชัดเจน
- [ ] ตรวจต้นฉบับ ก.ค.ศ. แยกจากคู่มือวิจัยก่อนสรุปว่าเอกสารพร้อมยื่นวิทยฐานะ
