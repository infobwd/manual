## เกณฑ์ด้านที่ 3 ที่ควรใช้ตรวจ
เอกสาร ก.ค.ศ. ฉบับรวมแก้ไขระบุว่าการเลื่อนเป็น **ผู้อำนวยการเชี่ยวชาญ** ต้องมีผลงานทางวิชาการเป็นงานวิจัยเกี่ยวกับการพัฒนาสถานศึกษา **หรือ** นวัตกรรมการบริหารสถานศึกษา จำนวน **1 รายการ** ใน PDF ที่แปลงจาก Word; แยกจากเกณฑ์ **เชี่ยวชาญพิเศษ** ซึ่งมีข้อกำหนดเพิ่มเติมเกี่ยวกับงานวิจัยและการเผยแพร่ในวารสาร TCI. ต้องตรวจหนังสือแก้ไขใหม่ก่อนใช้ยื่นจริง

## WD Growth Together — ช่องว่างหลักฐานที่ควรเตรียม
| มิติ | หลักฐานที่ควรมี |
|---|---|
| ปัญหาและ baseline | SAR/NT และผล A1.0 พร้อมคำจำกัดความตัวชี้วัด |
| รูปแบบการบริหาร | แผนผังบทบาทครู ผู้ปกครอง ผู้บริหาร และวงรอบ PLC |
| เครื่องมือ | Blueprint, rubric, แบบบันทึกกระดาษ/ระบบ, การตรวจคุณภาพ |
| การใช้จริง | วันที่ดำเนินการ, หลักฐานการปรับแผนรายบุคคล, การติดตาม |
| ผลลัพธ์ | ก่อน-หลังเทียบกับตนเอง, ความครบถ้วนข้อมูล, ตัวอย่างตรวจสอบย้อนกลับ |
| จริยธรรมข้อมูล | รหัสนักเรียนแทนชื่อ, สิทธิ์เข้าถึง, ความยินยอมตามความเหมาะสม |
