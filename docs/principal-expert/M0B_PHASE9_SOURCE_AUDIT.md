# M0-B ระยะ 9 — ตรวจสอบแหล่งต้นฉบับและ PDF (24 ต.ค. 2569)

## ผลการตรวจ 22 ระเบียน
- วรรณกรรม 7 รายการ: เปิดหน้าเผยแพร่หรือหน้าแสดงข้อมูลของวารสารได้; **ตรวจหน้าเว็บเท่านั้น ไม่ใช่การรับรองข้อมูลทุกช่อง**
- กลุ่มผู้ผ่านเบื้องต้น 15 ราย: เปิดข่าวรองรับ 3 กลุ่มได้ แต่ **ยังไม่ได้ตรวจรายชื่อ/ชื่อผลงานรายบุคคลเทียบประกาศ ก.ค.ศ. ต้นฉบับ**; field `source_verification_scope` บอกข้อจำกัดนี้
- PDF ฉบับเต็มที่เปิดได้จริง 3 รายการ (L05, L06, L07); อีก 4 รายการยังไม่บันทึก URL PDF เพราะยังไม่เปิดไฟล์ยืนยัน

## สิ่งที่แก้ในข้อมูล
- เพิ่ม `pdf_url`, `pdf_status`, `link_checked_at`, `source_verification_scope`
- แก้ L07 ปีเผยแพร่เป็น 2568 (เว็บไซต์ระบุ 31 ธ.ค. 2025) และผู้แต่งเป็น ณิชากร ขำสุนทร / พาที เกศธนากร
- เติมผู้แต่ง L05 และ L06 ตามหน้าบทความ; แยก URL preview เดิมเป็น `discovery_page_url` และเปลี่ยน `source_page_url` ไปหน้าเว็บไซต์วารสารเจ้าของบทความ
- ไม่ยกระดับ `verification_level` ของผลงานทั่วไปให้เป็นผู้ผ่านวิทยฐานะ
