# M0-B ระยะ 14 — แผนแม่บททบทวนวรรณกรรม WD Growth Together

**สถานะ:** แผนรอดำเนินการ (ยังไม่ใช่ผลการวิจัย)  
**โครงการ:** เตรียมผลงานเพื่อขอมีหรือเลื่อนวิทยฐานะผู้อำนวยการสถานศึกษาเชี่ยวชาญ  
**Repository:** `infobwd/manual`  
**ระบบข้อมูลต้นทาง:** `infobwd/wd-standard` (Private; ไม่ย้ายข้อมูลส่วนบุคคลมาไว้ใน repo สาธารณะ)  
**วันที่จัดทำ:** 24 ตุลาคม 2569

## 1. เป้าหมายและหลักการ
สร้างฐานแนวคิดที่ตรวจสอบย้อนกลับได้สำหรับ **WD Growth Together — รูปแบบการบริหารเพื่อพัฒนาผู้เรียนรายบุคคลโดยใช้ข้อมูลและ PLC เป็นฐาน** โดยแยกอย่างเคร่งครัดระหว่าง (ก) ผลวิจัยของผู้อื่น (ข) กรอบ/สมมติฐานของเรา (ค) หลักฐานผลการดำเนินงานจริง

งาน L05–L07 ที่ตรวจ PDF และเลขหน้าแล้วใน M0-B ระยะ 13–13.1 เป็นฐานด้าน PLC เท่านั้น **ไม่ถือว่าครอบคลุมองค์ประกอบทั้งหมด** และไม่ใช่หลักฐานว่ารูปแบบ WD Growth ได้ผลแล้ว

## 2. หกด้านที่ต้องครอบคลุม
| รหัส | ประเด็น | สิ่งที่ต้องตอบให้ได้ | หลักฐานที่ควรค้น |
|---|---|---|---|
| T1 | PLC / การบริหารวิชาการ | ผู้บริหารสนับสนุนวงจรเรียนรู้ของครูอย่างไร | L05–L07 + งานคุณภาพสูงเพิ่มเติม |
| T2 | Data-Driven Leadership | ใช้ข้อมูลรายคน/รายทักษะตัดสินใจและติดตามอย่างไร | งานบริหารโดยใช้ข้อมูลและ data literacy |
| T3 | Formative Assessment | ประเมินระหว่างเรียน/ให้ข้อมูลย้อนกลับอย่างไร | งานคุณภาพเครื่องมือ rubric และ assessment for learning |
| T4 | Personalized Learning | วางแผนพัฒนาผู้เรียนตามความต้องการอย่างไร | งาน intervention, differentiated instruction, growth monitoring |
| T5 | Teacher–Parent Partnership | ครูหลายคนและผู้ปกครองมีส่วนร่วมโดยไม่เพิ่มภาระเกินจำเป็นอย่างไร | งาน family engagement และ collaborative practice |
| T6 | R&D / Evaluation | พัฒนา ตรวจคุณภาพ ทดลอง และประเมินรูปแบบบริหารอย่างไร | งาน design-based research, R&D, program evaluation |

**จำนวนเป้าหมายเบื้องต้น:** 12–18 แหล่งคุณภาพครอบคลุมหกด้าน ไม่ใช่ข้อบังคับของ ก.ค.ศ. และไม่ใช้จำนวนแทนคุณภาพ

## 3. แผนปฏิบัติการและเงื่อนไขผ่าน
### 14.1 — วางแผนทบทวนวรรณกรรม
- [ ] นิยามคำถามหลัก/คำถามย่อยของรูปแบบ WD Growth Together
- [ ] สร้างชุดคำค้นไทย–อังกฤษและแหล่งค้น (ThaiJO, ERIC, Google Scholar, วารสารต้นฉบับ ฯลฯ)
- [ ] กำหนดเกณฑ์รับเข้า: เกี่ยวข้องกับ T1–T6, มีข้อมูลบรรณานุกรมและวิธีวิจัยตรวจได้, มีต้นฉบับ/บทคัดย่อจากแหล่งที่เชื่อถือได้
- [ ] กำหนดเกณฑ์คัดออก: แหล่งไม่ชัดเจน, อ้างอิงต่อโดยไม่พบต้นฉบับ, ไม่ตรงประเด็น, รายการซ้ำ
- [ ] สร้างตารางช่องว่างหลักฐาน (evidence gap matrix) และรูปแบบบันทึกการคัดกรอง
- **Gate 14.1:** มี protocol, คำค้น, เกณฑ์รับเข้า/คัดออก และ matrix ครบก่อนเริ่มค้นจำนวนมาก

### 14.2 — ค้นและตรวจต้นฉบับ
- [ ] ค้นทั้งงานไทยและต่างประเทศ โดยบันทึกวันที่ค้น ฐานข้อมูล คำค้น และจำนวนที่พบ
- [ ] ตรวจชื่อผู้แต่ง ปี ชื่อเรื่อง วารสาร DOI/URL จากหน้าผู้เผยแพร่
- [ ] อ่านบทคัดย่อเพื่อคัดกรอง แล้วอ่าน PDF ฉบับเต็มเมื่อเข้าถึงได้
- [ ] บันทึกเลขหน้าวารสารและเลขหน้า PDF แยกกัน; หากเปิด PDF ไม่ได้ให้ระบุ `pending` ไม่เดาเลขหน้า
- [ ] บันทึกงานที่มีผลขัดแย้ง ข้อจำกัด หรือหลักฐานไม่สนับสนุนด้วย
- **Gate 14.2:** ได้ชุดงานคุณภาพที่กระจายครบ T1–T6 พร้อมสถานะการตรวจต้นฉบับรายเรื่อง

### 14.3 — สังเคราะห์กรอบแนวคิด
- [ ] ตารางสังเคราะห์: วัตถุประสงค์ วิธีวิจัย กลุ่มตัวอย่าง เครื่องมือ ข้อค้นพบ ข้อจำกัด เลขหน้า
- [ ] เชื่อมแต่ละแหล่งกับองค์ประกอบของ WD Growth และเหตุผลเชิงทฤษฎี
- [ ] ระบุช่องว่างที่งานเดิมยังตอบไม่ได้ และข้อเสนอคุณค่าของรูปแบบ WD Growth
- [ ] ร่างกรอบแนวคิด/ทฤษฎีการเปลี่ยนแปลง (inputs → processes → outputs → outcomes) โดยไม่กล่าวอ้างผลก่อนมีข้อมูลจริง
- **Gate 14.3:** ทุกองค์ประกอบมีเหตุผลรองรับ ตรวจย้อนกลับถึงต้นฉบับได้ และแยกข้ออนุมานจากข้อค้นพบ

### 14.4 — เชื่อมกับหลักฐานการดำเนินงานจริง
- [ ] ตรวจสถานะ Baseline A1.0 ทั้ง 9 ระดับชั้นจากแหล่งที่มีสิทธิ์เข้าถึง
- [ ] ตรวจ rubric, แบบประเมิน, ความตรง/ความเชื่อมั่น และความเทียบเคียงก่อน–หลัง
- [ ] ตรวจแผนพัฒนารายบุคคล วงจร PLC บทบาทครูหลายคน และผู้ปกครอง
- [ ] กำหนดผู้บันทึก/ผู้ตรวจยืนยัน หลักฐานกระดาษ–ระบบ และการคุ้มครองข้อมูลผู้เรียน
- [ ] ระบุข้อมูลที่มีแล้ว / อยู่ระหว่างเก็บ / ยังไม่มี อย่างตรงไปตรงมา
- [ ] ตรวจหลักเกณฑ์ ก.ค.ศ. ฉบับต้นฉบับและหลักฐานตามเกณฑ์ก่อนเตรียมส่งจริง
- **Gate 14.4:** มี evidence register และแผนประเมินผลที่วัดการเปลี่ยนแปลงรายบุคคลได้ โดยไม่เผยแพร่ข้อมูลส่วนบุคคล

## 4. รูปแบบตารางหลักฐานขั้นต่ำ
| ID | ด้าน T1–T6 | อ้างอิงบรรณานุกรม | ประเภท/วิธีวิจัย | กลุ่มตัวอย่าง | เครื่องมือ | ผลหลัก | ข้อจำกัด | หน้าอ้างอิง | สถานะ PDF | นัยต่อ WD |
|---|---|---|---|---|---|---|---|---|---|---|

สถานะที่ใช้: `candidate` → `publisher_verified` → `abstract_reviewed` → `full_text_checked` → `page_verified`. ห้ามเลื่อนสถานะโดยไม่มีหลักฐาน
