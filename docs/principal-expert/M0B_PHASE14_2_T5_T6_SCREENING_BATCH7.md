## 2. แหล่งหลักฐาน T5
### T5-01 (ขยายจากชุด 6): EEF, *Working with Parents to Support Children's Learning* (2018)
หน้าต้นทาง: https://educationendowmentfoundation.org.uk/education-evidence/guidance-reports/supporting-parents

จากหน้าเผยแพร่: เป็น guidance สำหรับครู/ผู้บริหารทั้งประถมและมัธยม; มีคำแนะนำ 4 ข้อ; ความสัมพันธ์ของการมีส่วนร่วมของผู้ปกครองกับผลการเรียนมีหลักฐาน แต่ประสิทธิผลของวิธีดึงผู้ปกครองเข้าร่วม **แตกต่างกัน** และการช่วยเหลือเด็กในชั้นเรียนโดยตรงบางแบบมีหลักฐานแข็งแรงกว่ากิจกรรมผู้ปกครองบางแบบ

**สถานะ:** `publisher_verified` (ไม่ใช่ `page_verified`); ยังไม่ได้อ่าน PDF ทั้งฉบับหรือยืนยันเลขหน้า

**นัยต่อ WD:** กำหนดเป้าหมายการสื่อสารกับผู้ปกครองเป็นกิจกรรมสนับสนุนการเรียนที่ทำได้จริง ติดตามผลโดยสมัครใจ ไม่ใช้จำนวนข้อความ/การเข้าร่วมเป็นตัวแทนผลการเรียน และต้องไม่เผยข้อมูลเด็กอื่น

## 4. ตารางสังเคราะห์เบื้องต้น (ข้อเสนอการออกแบบ WD)
| องค์ประกอบ WD | แนวคิดต้นทาง | สิ่งที่จะต้องมีในหลักฐาน WD จริง | ข้อจำกัด |
|---|---|---|---|
| สื่อสารและร่วมมือกับผู้ปกครอง | T5-01 | เป้าหมายทักษะที่ผู้ปกครองเข้าใจได้, กิจกรรมสั้นที่ทำได้, การตอบรับโดยสมัครใจ, สิทธิ์เข้าถึงข้อมูล | การเข้าร่วมไม่เท่ากับผลสัมฤทธิ์ |
| วงจรการพัฒนารายบุคคล | T4 เดิม + T6-03 | baseline → แผน → ลงมือ → feedback → วัดซ้ำ → ปรับแผน | ความก้าวหน้าอาจมีปัจจัยอื่นร่วม |
| คุณภาพข้อสรุปเชิงผล | T6-01/02 | ข้อมูลก่อน–หลัง เครื่องมือเทียบเคียงได้ ข้อมูลขาดหาย ความเที่ยง และวิธีวิเคราะห์ | ก่อน–หลังกลุ่มเดียวไม่ยืนยันเหตุ–ผลได้ |
| รูปแบบการบริหาร | T6-03/04 | input → process → output → outcome พร้อมสมมติฐาน ตัวชี้วัด และแหล่งหลักฐาน | เป็นกรอบที่ต้องทดสอบ ไม่ใช่ผลสำเร็จ |
