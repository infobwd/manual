## 3. ศึกษาผู้ผ่านการประเมิน: แยกระดับความน่าเชื่อถือ
**ชั้น A — Verified approved exemplar:** มีคำสั่ง/ประกาศราชการที่ระบุผู้ผ่านและวิทยฐานะ + ผลงานที่ตรวจได้ว่าเป็นของผู้ผ่านรายนั้น + ยืนยันช่วงเวลา/เกณฑ์เดียวกัน. ใช้เป็นกรณีศึกษาเชิงลึกได้.

**ชั้น B — Approval event only:** มีข่าว/มติพิจารณาหรืออนุมัติ แต่ไม่มีผลงานฉบับเผยแพร่/ไม่ทราบผลสุดท้าย. ใช้ค้นต่อ **ห้ามเรียกผลงานต้นแบบผู้ผ่าน**.

**ชั้น C — Public sample / commentary:** คลิป/บทความ/โมเดลที่เผยแพร่ทั่วไป แต่ไม่มีหลักฐานคำสั่งอนุมัติของเจ้าของผลงาน. ใช้เรียนรู้วิธีเล่าเรื่องเท่านั้น.

## 4. กรอบวิเคราะห์กรณีศึกษาที่จะใช้ (เมื่อพบชั้น A)
1. **Problem:** ปัญหาต้นทางและข้อมูลฐานจริง; เหตุใดผู้บริหารจึงเลือกโจทย์นี้
2. **Leadership contribution:** ผู้ขอออกแบบ/ตัดสินใจ/ขับเคลื่อนอะไรด้วยตนเอง
3. **Model architecture:** องค์ประกอบ กลไก บทบาทครู ผู้ปกครอง ชุมชน และวงจรปรับปรุง
4. **Implementation fidelity:** ทดลองใช้กี่รอบ ระยะเวลา ครอบคลุมใคร อุปสรรคและการปรับ
5. **Outcomes:** ผลผู้เรียน ครู สถานศึกษา วิธีวัด ความเทียบเคียง ข้อจำกัด
6. **Academic rigor:** วิธีสร้าง/พัฒนานวัตกรรมหรือวิธีวิจัย เครื่องมือ ตรวจคุณภาพและการวิเคราะห์
7. **Transferability:** สิ่งที่ผู้อื่นนำไปปรับใช้ได้ การยอมรับ/การเผยแพร่ตามหลักฐานจริง
8. **Submission narrative:** สอดคล้องด้าน 1–3 และไฟล์ที่กฎกำหนดอย่างไร

## 5. วิเคราะห์เชิงยุทธศาสตร์ต่อ WD Growth Together
- **สิ่งที่ควรยืมเป็นหลักการ:** เล่าเรื่องปัญหาจริง→ภาวะผู้นำ→การออกแบบระบบ→การทดลอง→ผลลัพธ์→การพัฒนาต่อ; ยืนยันความเป็นเจ้าของงานและความร่วมมือของครู
- **สิ่งที่ไม่ควรลอก:** ชื่อ MODEL, แผนภาพ, เนื้อหารายงาน, ค่าสถิติ, ผลสำเร็จ, หรือการอ้างรางวัลของผู้อื่น
- **ช่องว่างเร่งด่วน:** บันทึกการตัดสินใจของผู้บริหาร, ผล Baseline ที่ตรวจรับ, PLC 7 สัปดาห์จริง, การนิเทศ/Mentor, ผล retest ที่เทียบเคียง, คุณภาพเครื่องมือและข้อจำกัด, ต้นฉบับผลงานทางวิชาการ
- **สมมติฐานที่ต้องพิสูจน์:** การพัฒนาครูด้วย PLC และ Mentor เมื่อใช้ข้อมูลรายบุคคลจะทำให้การสอนตอบโจทย์และผลผู้เรียนดีขึ้นอย่างไร; ห้ามอ้างเหตุและผลจากคะแนนก่อน–หลังเพียงอย่างเดียว
