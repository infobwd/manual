# WD Growth Insights — แผนสารสนเทศรายชั้น ป.1–ป.5 (2569)

สถานะ: DESIGN / SOURCE AUDIT REQUIRED / ไม่เผยแพร่คะแนนที่ยังไม่ตรวจรับ

## วัตถุประสงค์
สร้างหนังสือสารสนเทศ 5 เล่ม ชั้นละหนึ่งเล่ม สำหรับครู ผู้ปกครอง และผู้บริหาร แยกตามวิชาและทักษะ พร้อมโครงสร้างรองรับ Baseline → ติดตามระหว่างเรียน → วันเติบโต → รอบต่อไป. แยกหนังสือแนวทางพัฒนาครูต่างหาก

## ชุดหนังสือ
1. WD Growth Insights ป.1 — รอตรวจข้อมูลจริง/นิยามทักษะจาก wd-standard
2. WD Growth Insights ป.2 — รอตรวจข้อมูลจริง/นิยามทักษะจาก wd-standard
3. WD Growth Insights ป.3 — รอตรวจข้อมูลจริง/นิยามทักษะจาก wd-standard
4. WD Growth Insights ป.4 — รอตรวจข้อมูลจริง/นิยามทักษะจาก wd-standard
5. WD Growth Insights ป.5 — มีเอกสาร reconciliation ฉบับร่าง แต่รอครูตรวจรับก่อนสรุป

**ห้ามสมมติว่าข้อมูล ป.1–ป.4 ครบทุกวิชา ทุกทักษะ หรือผ่านการตรวจรับแล้ว** ต้องทำ source inventory รายชั้นและรายรอบก่อนเติมตัวเลข

## โครงสร้างมาตรฐานต่อเล่ม
- ปก: ชั้น ปีการศึกษา รอบประเมิน สถานะข้อมูล วันที่ปรับปรุง
- อธิบายการประเมิน: วัดอะไร จำนวนผู้มีสิทธิ์/ประเมินจริง/รอตรวจรับ/ขาดเรียน/ยังไม่ประเมิน
- ภาพรวมระดับชั้น: เฉพาะสถิติรวมที่เผยแพร่ได้ พร้อมจำนวนฐานและข้อจำกัด
- ภาษาไทย: แยกทักษะตาม blueprint จริงของชั้น ไม่ใช้คะแนนรวมแทนรายทักษะ
- คณิตศาสตร์: แยกข้อ/สมรรถนะตาม blueprint และรายงานข้อที่ต้องพัฒนา
- ภาษาอังกฤษ: แยกฟัง พูด อ่าน เขียน และสถานะ missing แยกจาก 0
- ข้อค้นพบและคำอธิบายภาษาง่ายสำหรับผู้ปกครอง (ไม่วินิจฉัยหรือจัดอันดับเด็ก)
- ติดตามพัฒนาการ: ตาราง baseline/รอบถัดไปและกราฟเมื่อมีข้อมูลที่เปรียบเทียบกันได้
- แหล่งข้อมูล รุ่นเกณฑ์ การตรวจรับ ข้อจำกัด และวันที่ปรับปรุง

## โครงสร้างข้อมูลขั้นต่ำ
academic_year, grade, assessment_round, instrument_version, subject, skill_id, skill_name, max_score, assessed_count, eligible_count, pending_count, absent_count, not_observed_count, verified_at, publication_approval, aggregate_metrics.

ต้องคงข้อมูลรายข้อ/รายคนในระบบที่มีสิทธิ์เท่านั้น ไม่ฝังในไฟล์หนังสือสาธารณะ. หากขนาดกลุ่มเล็กหรือแยกกลุ่มแล้วอาจระบุตัวบุคคล ให้ซ่อนค่าหรือใช้คำอธิบายเชิงคุณภาพ. ผู้ปกครองดูผลบุตรของตนเฉพาะช่องทางยืนยันตัวตนที่ได้รับอนุมัติ ไม่ผ่านหนังสือสาธารณะ

## หลักการเปรียบเทียบข้ามรอบ
ใช้ทักษะ/เกณฑ์เดียวกันหรือมี mapping ที่ตรวจรับ; แสดง n ของแต่ละรอบ; ไม่เทียบคะแนนดิบต่างเครื่องมือโดยไม่มีคำอธิบาย; ไม่แปลง PENDING/ABSENT/N/O เป็น 0; เก็บ snapshot รุ่นเดิมเพื่อย้อนตรวจสอบ

## ลำดับดำเนินงานและข้อควรระวัง
1. Audit แหล่งคะแนน ป.1–ป.5 ใน private wd-standard และ Host แบบ read-only; จัดทำ source matrix พร้อมสถานะรับรอง
2. ออกแบบ schema สารสนเทศแบบไม่เปิดเผยรายคนและ review โดยครู
3. สร้างต้นฉบับ 5 เล่มโดยใช้ข้อมูลที่ตรวจรับแล้วเท่านั้น; ถ้ายังไม่ครบให้ระบุ 'รอตรวจรับ' แทนตัวเลข
4. ทำหนังสือแนวทางพัฒนาครูแยกเล่มและเชื่อมไปยัง PLC
5. PR integration แยกจาก UI-MIG/FLIP; ทดสอบ Reader/Flipbook/PWA/มือถือ/แท็บเล็ต/เสียงอ่าน
6. ก่อนเผยแพร่ต้องผ่าน data-owner approval และ privacy review โดยเฉพาะห้องเรียนขนาดเล็ก

## แผนติดตาม
เพิ่ม assessment_round โดยไม่ทับ baseline; สรุปความก้าวหน้ารายทักษะและจำนวนผู้ได้รับการติดตาม พร้อมวันประเมินและแหล่งหลักฐาน. หนังสืออาจมีรุ่นปรับปรุงตามรอบ แต่ต้องเก็บวันและเวอร์ชันเพื่ออ้างอิงย้อนหลัง
