คู่มือผู้บริหาร Mentor และ ID Plan ปีงบประมาณ 2570

อ้างอิงประกาศ ก.ค.ศ. ว 11/2569 ข้อ (3)–(5) ตามเอกสารที่ผู้ใช้แนบ (ภาพหน้า 2 จาก 4): การวางแนวทางพัฒนาอย่างเป็นระบบ แผนพัฒนาประจำปีทั้งระดับหน่วยงานและรายบุคคล และบทบาท Mentor.

ตรวจทานก่อนเผยแพร่: อ่าน PDF ครบทุกหน้า โดยเฉพาะเงื่อนไขเฉพาะและวันใช้บังคับ, ตรวจข้อกำหนด สพฐ./เขต, ตรวจ JS syntax, ทดสอบอ่าน 10 หน้า บน iPhone/iPad โหมดกลางคืน/ถนอมสายตา การอ่านต่อและออฟไลน์. คู่มือนี้เป็นฉบับแนะแนว ไม่ใช่แบบฟอร์มทางราชการ.
