## ตรวจแหล่งข้อมูล ณ 23 ต.ค. 2569
- พบ `ขั้นพื้นฐาน 68 บ้านวังด้ง.pdf` ใน Library เป็น SAR **ระดับการศึกษาขั้นพื้นฐาน** 76 หน้า ไม่ใช่ SAR ปฐมวัย
- ค้นหา SAR ปฐมวัย 2568 ใน Library และค้นหาใน PA repo แล้ว ยังไม่พบต้นฉบับที่ตรวจสอบได้
- **ห้าม** นำตัวเลขนักเรียน ป.1–ป.6 หรือมาตรฐานขั้นพื้นฐานไปอ้างเป็นผลประเมินปฐมวัย และห้ามสมมติร้อยละพัฒนาการ

## โครงหนังสือหลังได้รับต้นฉบับ
1. รู้จัก SAR ปฐมวัย 2568 และขอบเขตข้อมูล
2. ภาพรวมเด็กปฐมวัยและการจัดประสบการณ์ (ข้อมูลรวม ไม่ระบุเด็ก)
3. พัฒนาการด้านร่างกาย — ผลจริง/เป้าหมาย/หลักฐาน
4. พัฒนาการด้านอารมณ์–จิตใจ
5. พัฒนาการด้านสังคม
6. พัฒนาการด้านสติปัญญา
7. มาตรฐานด้านกระบวนการบริหารและจัดการ / การจัดประสบการณ์ ตามหัวข้อที่มีจริงใน SAR
8. จุดเด่น จุดควรพัฒนา และแนวทางพัฒนาต่อ
9. สรุปสำหรับผู้ปกครอง พร้อมที่มาและข้อจำกัด
