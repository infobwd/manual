## การอ่านผลอย่างถูกต้อง
- `PLANNED_ONLY` หมายถึงเอกสารที่ตรวจมีแผน แต่ **ยังไม่ยืนยันหลักฐานการดำเนินงาน** ไม่ใช่ข้อสรุปว่าไม่เคยทำกิจกรรม
- `HISTORICAL_TECHNICAL_STATUS_ONLY` เป็นบันทึกสถานะเชิงเทคนิคในอดีต ไม่ใช่การยืนยัน Host Production ณ วันนี้
- ผลการอ่านเอกสารแผนไม่ยกระดับ `original_verified` ของหลักฐานการปฏิบัติจริง และไม่ยกระดับ `evidence_acceptance`
- เอกสารหลักฐานที่มีข้อมูลส่วนบุคคล รวมทั้ง hash และ path ต้นฉบับ ให้เก็บใน Private ที่มีสิทธิ์เหมาะสมเท่านั้น
- Source Lock ของหนังสือแก้ไข ก.ค.ศ. ยังไม่ปิด

## สิ่งที่ต้องดำเนินการใน R9B รอบ 2
1. เจ้าของงาน PLC ตรวจรายงานประชุม 7 สัปดาห์จริง: วัน เวลา ผู้เข้าร่วม มติ ทดลองใช้ ติดตามผล และการลงนาม/อนุมัติ
2. ผู้รับผิดชอบนิเทศตรวจ Coaching log พร้อมบันทึกหลังนิเทศและผลแก้ไข
3. ผู้บริหาร/ธุรการตรวจคำสั่ง มติ บันทึกใช้ข้อมูลตัดสินใจและรายงานติดตามผลที่ลงวันที่
4. งานวัดผลตรวจ Baseline–Retest สองรอบจริงโดยตรวจความเทียบเคียงเครื่องมือและตัวหาร/ตัวตั้ง **ในพื้นที่ Private เท่านั้น**
5. เมื่อได้รับต้นฉบับจริง จึงบันทึก provenance รายชิ้นในทะเบียน Private และทำ mapping รายเกณฑ์ 60 ข้อ; สรุปสาธารณะได้เฉพาะข้อมูลผ่านอนุมัติ
