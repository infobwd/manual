# M1 รอบที่ 7 — ตรวจภาพ iPhone และปรับการอ่าน

วันที่ 24 ต.ค. 2569 · แหล่งตรวจ: ภาพหน้าจอ iPhone ที่ผู้ใช้งานส่งมา 4 ภาพ

## สิ่งที่ตรวจได้จากภาพ
- ตัวกรองด้านที่ 2 แสดง 20/60 รายการ
- ตัวกรอง R3-A แสดง 10/60 รายการ
- ตัวกรอง R3-B แสดง 15/60 รายการ
- สรุป 60 รายการ / รับรองแล้ว 0 / ยังไม่รับรอง 60 สอดคล้องกับทะเบียนรอบที่ 5
- ป้ายสถานะและข้อความอ้างอิงปรากฏ แต่พื้นที่ด้านบนของจอมีคำเตือนยาวและข้อมูลกลุ่มหลักฐานยังเป็นรหัสภาษาอังกฤษ

## การปรับใน PR
1. ทำคำเตือนแบบกดขยาย โดยคงสาระสำคัญที่มองเห็นก่อนเปิด
2. เพิ่มระยะปลอดภัยบนและล่างของ iPhone
3. แสดงชื่อกลุ่มหลักฐานเป็นภาษาไทย โดยยังค้นจากรหัสเดิมได้
4. เพิ่มคำอธิบายจุดตรวจรับ R3-A ถึง R3-D แบบกดขยาย
5. เพิ่มรุ่น cache ของแอปเป็น 1.3.29
