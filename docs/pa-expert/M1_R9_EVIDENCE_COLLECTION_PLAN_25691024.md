# M1-R9 — แผนรวบรวมและตรวจหลักฐานจริง (24 ต.ค. 2569)

## วัตถุประสงค์
ต่อยอด R8A (ทะเบียนผู้สมัคร 60 เกณฑ์), R8B (สำรวจบางส่วน) และ R8C (หน้าเว็บผ่านการตรวจรับบน iPhone) สู่ **ชุดงานขอหลักฐานต้นฉบับ** โดยไม่อ้างว่าได้รับหลักฐานหรือผ่านเกณฑ์แล้ว

## ชุดหลักฐานที่ต้องขอ
ทะเบียนประกอบ `M1_R9_EVIDENCE_COLLECTION_REGISTER_25691024.csv` กำหนด 14 ชุด E01–E14: R3-A 3, R3-B 3, R3-C 5, R3-D 3. บทบาทเจ้าของงานเป็น **ข้อเสนอ** ยังไม่ใช่คำสั่งแต่งตั้ง

### ลำดับการรวบรวม
1. **PLC และ Coaching (E04–E06):** ขอรายงานแต่ละสัปดาห์/บันทึกนิเทศ/ผลติดตามจริง พร้อมวัน ผู้รับผิดชอบและหลักฐานการอนุมัติ
2. **การตัดสินใจผู้บริหาร (E07–E11):** ขอคำสั่ง มติ บันทึกเหตุผลที่ใช้ข้อมูล และหลักฐานติดตามผล; ห้ามถือแผนงานเป็นการดำเนินงานจริง
3. **ผลลัพธ์ (E12–E14):** ตรวจความเทียบเคียงเครื่องมือ รุ่นแบบทดสอบ ตัวหาร/ตัวตั้ง การขาดข้อมูล และผลอนุมัติ ก่อนทำสรุปแบบรวม
4. **Baseline และแผนรายคน (E01–E03):** ตรวจต้นฉบับในพื้นที่ปลอดภัย ไม่คัดลอกข้อมูลนักเรียนเข้าคลังสาธารณะ

## วิธีตรวจรับรายชุด
- `TO_COLLECT` หมายถึงกำหนดรายการต้องขอ ไม่ได้แปลว่าไม่มีเอกสารอยู่จริง
- ตรวจการมีอยู่และสิทธิการเข้าถึงต้นฉบับ จากนั้นบันทึกวัน/เวอร์ชัน/ผู้อนุมัติและ SHA-256 ในพื้นที่ Private ที่ได้รับอนุญาต
- ตรวจความตรงตามเกณฑ์ **รายข้อ**; รหัสรูปแบบ `D1-04.*` ใน CSV เป็นเพียง candidate group ไม่ใช่การแมปยืนยันครบ 5 ข้อ
- แยก **original verification**, **formal evidence acceptance**, และ **official criteria/amendment Source Lock** เป็นสามประตูอิสระ
- ผู้ตรวจรับต้องเป็นผู้ที่มีอำนาจตามกระบวนการที่กำหนด; ไม่มีการรับรองจากการคลิกเว็บหรือจาก GitHub Merge
- ไม่อัปโหลดชื่อ เลขที่ คะแนนรายคน เอกสารต้นฉบับส่วนบุคคล หรือที่อยู่ private repository สู่ public `infobwd/manual`

## สถานะ ณ วันที่จัดทำ
- ชุดงานที่วางแผน: **14** (ยังไม่มีการรับรอง)
- เกณฑ์ย่อยในทะเบียน: **60** (ยังไม่รับรอง 60)
- Source Lock: **BLOCKED_AMENDMENTS**
- R8B พบเอกสารที่เลือกสำรวจ 8 ฉบับ แต่ไม่สามารถนับเป็น 8 ชุดหลักฐานที่ผ่านตรวจรับใน R9
- ไม่เปลี่ยนข้อมูล JSON ที่ใช้แสดงหน้า R8C หรือสถานะ R8A

## Gate R9-A / R9-B / R9-C
- **R9-A:** ตรวจรับรายการต้องขอและแต่งตั้งเจ้าของงานจริง
- **R9-B:** ตรวจต้นฉบับภายใน Private อย่างเป็นระบบ บันทึก provenance/verification แบบมีวันและผู้ตรวจ
- **R9-C:** ทำ crosswalk รายข้อ 60 เกณฑ์จากหลักฐานที่ตรวจแล้ว และเผยแพร่เฉพาะผลสรุปที่ผ่านอนุมัติ
