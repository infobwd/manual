## ขอบเขตและหลักฐานที่อ่านจริง
ตรวจไฟล์จาก `infobwd/wd-standard` (private, default branch) แบบ read-only:
1. `docs/WD_GROWTH_P3_BASELINE_A1_2569_PARTIAL_REVIEW.md` — รายงานร่างผล Baseline ป.3 ลงวันที่ 18 ต.ค. 2569; อ้างอิงกระดาษ 20 ภาพและระบุชัดว่า **รอครูตรวจรับ**. รายงานมีการสรุปคะแนนระดับกลุ่มแต่ **ไม่ทราบจำนวนนักเรียนตามทะเบียน** และบางรายวิชามีข้อมูลไม่ครบ. ไม่คัดลอกคะแนนหรือเลขที่นักเรียนลงเอกสารสาธารณะนี้.
2. `docs/WD_GROWTH_ASSESSMENT_DESIGN.md` — แบบออกแบบการวัด, การแยก baseline/practice/formative/retest และเกณฑ์ความเทียบเคียง; สถานะ PROPOSED.
3. `docs/WD_GROWTH_MASTER_PLAN.md` — operating model ของครู ผู้บริหาร ผู้ปกครอง และ PLC; สถานะในส่วนหัว PROPOSED/DOCUMENT-ONLY.
4. `docs/WD_GROWTH_CURRENT_EXECUTION_STATUS.md` — รายงานสถานะการพัฒนาและการทดสอบตามเวลา; ส่วนหัวระบุ LAST REVIEWED 18 ต.ค. 2569 จึงไม่ถือเป็นหลักฐานยืนยันสภาพ Host ณ วันนี้.
5. `infobwd/manual/docs/pa-expert/M0_A_EXPERT_RUBRIC_MATRIX.md` — ดัชนีรูบริก 12 ตัวชี้วัด/60 ข้อย่อย (ถอดความจากคู่มือปี 2564; ยังไม่ผ่าน Source Lock).

ไฟล์บางชื่อที่ปรากฏในสถานะเก่า (`WD_GROWTH_H4F_KIOSK_SYNTHETIC_ACCEPTANCE.md`, `WD_GROWTH_BASELINE_VERIFICATION_HOST_HANDOFF.md`, `WD_GROWTH_H4_HOST_PREFLIGHT_AND_TDRS_ACCEPTANCE.md`) **ไม่พบที่ path ใน default branch ที่ลองอ่าน**. อาจอยู่ใน branch/PR อื่นหรือย้ายชื่อ; ไม่ถือว่าไม่มีเอกสารในทุก branch.

## ข้อกำกับ
- ข้อมูลผู้เรียน/ภาพกระดาษ/คะแนนรายคน/เลขที่/บันทึกครูจริงคงอยู่ในพื้นที่จำกัดสิทธิ์เท่านั้น.
- หลักฐาน Baseline ไม่เท่ากับผลการเติบโต และ QA software ไม่เท่ากับผลลัพธ์สถานศึกษา.
- ไม่ใช้คำว่า verified, complete, passed หรือ deployed โดยไม่มีหลักฐานใหม่ตามวันตรวจ.
- M0-A Source Lock ยัง BLOCKED ระหว่างตรวจหนังสือแก้ไขและเกณฑ์ปัจจุบัน.

**ข้อสรุป:** M1 รอบ 2 พบ *หลักฐาน Baseline ป.3 ฉบับร่างจริง* ใน private repo แต่ยังไม่มีหลักฐานเพียงพอสำหรับรับรองผลลัพธ์ผู้เรียน/ครู/สถานศึกษา; งาน P0 คือการยืนยันข้อมูลโดยครูและตรวจสถานะระบบจริง.
