# M1-R9C — ชุดประสานขอหลักฐานต้นฉบับจากโรงเรียน (24 ต.ค. 2569)

> **สถานะ: DRAFT REQUEST PACK — ยังไม่ได้ส่งหนังสือ/มอบหมาย/รับเอกสารจริง** เอกสารนี้เป็นแม่แบบสำหรับประสานผู้เก็บรักษาหลักฐานที่ได้รับอนุญาต ไม่ใช่การตรวจรับหลักฐานหรือคำสั่งราชการ

## เป้าหมาย
ปิดช่องว่างจาก R9B รอบ 1–2 โดยขอต้นฉบับ **การปฏิบัติงานจริง** ใน 4 กลุ่ม และจัดทำบันทึกการรับมอบในพื้นที่ Private ที่โรงเรียนกำหนด ห้ามนำไฟล์ต้นฉบับ ข้อมูลผู้เรียน หรือชื่อบุคคลขึ้นเว็บไซต์สาธารณะ

## ข้อความขอความร่วมมือ (ร่างสำหรับผู้บริหารพิจารณา)
เรียน ผู้รับผิดชอบงานวิชาการ งานนิเทศ/PLC งานธุรการ และงานวัดผล

เพื่อประกอบการตรวจสอบความครบถ้วนของหลักฐานการดำเนินงาน WD Growth Together ขอความร่วมมือผู้รับผิดชอบรวบรวมเอกสารต้นฉบับที่มีอยู่จริงตามรายการด้านล่าง โดยระบุวันที่จัดทำ/ดำเนินการ หน่วยงานผู้รับผิดชอบ การอนุมัติหรือการลงนาม (หากมี) และความเชื่อมโยงกับกิจกรรมที่ดำเนินการ ทั้งนี้ **หากยังไม่ดำเนินการหรือยังไม่มีเอกสาร ให้ระบุสถานะตามจริง ห้ามสร้างเอกสารย้อนหลังหรือเติมผลลัพธ์สมมติ** กรุณาส่งผ่านช่องทางภายในที่โรงเรียนอนุญาตเท่านั้น

## ขั้นตอนรับมอบและตรวจสอบ (Private only)
1. ผู้รับผิดชอบแจ้ง **มี/อยู่ระหว่างจัดทำ/ยังไม่มี/ไม่เกี่ยวข้อง** ตามข้อเท็จจริง; ห้ามนับการตอบรับว่าเป็นหลักฐานผ่าน
2. เจ้าหน้าที่ผู้มีสิทธิ์รับต้นฉบับในระบบภายใน และออกเลขอ้างอิงภายใน; บันทึกผู้ส่ง/ผู้ตรวจ วันรับ วันเอกสาร ประเภทฉบับลงนาม และ hash หากนโยบายอนุญาต
3. ตรวจ **ความแท้และความครบถ้วนของต้นฉบับ** แยกจากการประเมินว่าเข้าเกณฑ์ย่อยใด และแยกจากการรับรองทางการ
4. จัดทำสำเนาสรุปที่ไม่ระบุตัวบุคคล **หลังผู้มีอำนาจอนุมัติ** จึงค่อยพิจารณาอัปเดตทะเบียนสาธารณะ
5. ทวนหลักเกณฑ์ ก.ค.ศ. และฉบับแก้ไขที่ใช้จริง (Source Lock) ก่อนสรุปความสอดคล้องรายเกณฑ์
